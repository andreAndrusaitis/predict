# Predict Design System

Predict is a decision laboratory: analytical, calm and traceable rather than decorative or chatbot-like. Use a 12-column responsive grid, 8px spacing scale, readable sans typography, 8px control radius and 12px surface radius. Tokens must support light and dark modes from the start.

Neutral surfaces establish hierarchy; one restrained primary accent marks action; status always pairs color with icon and text. Charts use a fixed color-blind-accessible series palette, labels, tooltips and uncertainty bands. Cards explain a single metric, insight or risk and link to underlying assumptions. Data tables support density choice, keyboard navigation and empty/loading/error states.

Forms are progressively disclosed with inline validation. Builders expose assumptions, source, confidence and calibration status beside the value. Results always show run count, seed policy, model version, interval/distribution and a label such as “simulation frequency” or “model estimate”. Motion is brief and purposeful; focus states, contrast, semantic headings and `aria-live` progress updates meet WCAG AA.
